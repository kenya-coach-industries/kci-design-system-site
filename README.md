# KCI Design System (web page)

The public, view-only web page of the KCI design system, served by GitHub
Pages: https://kenya-coach-industries.github.io/kci-design-system-site/

This repository holds only the generated page. The design system itself
(tokens, logos, guide, PDFs) lives in the private `kci-design-system`
repository, and its source of truth is `design/` in `kci-workspace`.
Do not edit `index.html` here: rebuild it with `scripts/build-design-site`
and copy it with `scripts/publish-design-system` in `kci-workspace`.
